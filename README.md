This project uses a Random Forest model to diffrentiate between real human speech and synthetic/deepfake audio samples using Fast Fourier Transform (FFT).

To comply with Git repository file-size limits and respect dataset hosting regulations, the raw audio .wav and .flac files are excluded from this repository. 

To run this code locally:
1. Run pip install -r requirements.txt in terminal
2. Download data from public datasets ASVspoof2019 and NaturalSpeech3 and add them into the placeholder files under data/
3. Run main.py
